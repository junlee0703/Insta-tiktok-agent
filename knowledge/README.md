# Knowledge Base — Source Material

Drop reference material here: facts, stats, formulas, timelines, anything
factual you want pulled into content instead of made up.

## The rule

**For any factual/technical claim — a stat, a formula, a timeline detail, a
number, "how X actually works" — only use what's in this folder.** Don't
invent or rely on general background knowledge for specifics. If a topic
someone asks for isn't covered here, say so explicitly and ask for source
material instead of guessing or making something plausible-sounding up.

This applies to every platform's content — anywhere a post makes a factual
claim, not just one channel.

Doesn't apply to voice/structure/style (that's `linkedin/style_guide.md` and
`tiktok/style_guide.md`) or to generic framing/advice that isn't a specific
factual claim (e.g. "check in with a professional before deciding" doesn't
need a citation, but any specific number, date, or rule does).

**One source file can power multiple posts.** Making a video on a topic
doesn't retire that source material — come back to it later with a
different hook, different subset of points, or a different structural angle
for a separate post, rather than treating each source file as good for
exactly one video.

## Format

Drop in whatever's easiest — markdown, plain text, or PDF all work (PDFs get
parsed directly). No need to organize by topic ahead of time; loose notes,
pasted excerpts, or full documents are all fine. Just make the filename
descriptive and specific to what's inside it.
