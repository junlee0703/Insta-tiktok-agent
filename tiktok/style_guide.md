# TikTok Style Guide

Empty — this is where the trained voice/tone/structure guide goes, derived
from real swipe-file examples. Voice is niche-specific, so nothing ships here
by default; it is yours to build.

## Before drafting anything

Per `AGENTS.md`'s hard rules: don't invent scripts/copy from scratch until
this file (and `tiktok/examples/`) has real content. If it is still empty,
gather example posts in the target niche/voice first, derive the
patterns (hook style, pacing, sentence length, sign-off/CTA conventions),
and write them up here before drafting.

## What belongs here

Once you have swipe-file examples, document: hook-writing templates and any
capitalization conventions, caption length and structure, and sign-off/CTA
wording. Keep the raw examples themselves in `tiktok/examples/`.
